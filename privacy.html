Privacy Policy

Effective date: November 3, 2026

Windsor Daily ("the tool") is a personal desktop tool that publishes Royal Family news videos to its owner's YouTube channel, Windsor Daily. This policy explains which data the tool accesses through the YouTube API Services and what it does with it.

YouTube API Services

The tool uses the YouTube API Services. By using the tool, you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

Data the tool accesses

  • OAuth access token — granted by the channel owner through Google's sign-in screen, with the scopes youtube.upload, youtube.readonly and youtube.force-ssl.
  • Channel name (channels.list, own channel only) — checked to confirm the tool is connected to the right channel.
  • Own videos, playlists and comments (videos.insert, playlists, playlistItems, commentThreads.insert) — used to upload the owner's videos, add them to the owner's playlists and post one comment from the channel under each video. The IDs of these items are kept so that nothing is published twice.

The tool does not read other users' comments, channels, subscribers, viewing history, email address or any other personal information.

How the data is used and stored

  • Data is used only to publish the owner's videos on the owner's channel.
  • The access token and the list of published IDs are stored locally, on the owner's computer only. Nothing is sent to any server other than Google's.
  • No data is sold, shared with third parties, used for advertising or combined with other data.
  • The tool does not use cookies or tracking. This website does not collect any data.

Revoking access and deleting data

Access can be revoked at any time from the Google security settings page. Locally stored data (token and IDs) is deleted when access is revoked, and in any case within 30 days on request.

Changes

Any change to this policy will be published on this page with a new effective date.
